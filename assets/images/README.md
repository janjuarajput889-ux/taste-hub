Optimized starter photos are included in the category folders under `assets/images/menu/`. Replace a file with your own photo using the same filename, or change that item's Image path in Admin / Manage Menu.

The bundled JPGs are cropped to 900 pixels wide for responsive restaurant cards. If an item has no image or its file is missing, the menu displays `menu-placeholder.svg`. Admin uploads are resized and compressed before they are saved in this browser's localStorage.
